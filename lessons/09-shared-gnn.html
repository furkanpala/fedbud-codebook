Lesson 9

The optional shared graph network

Because the clients' sub-networks keep different parts, FedBUD offers an extra shared network that reads each sub-network's graph and changes the output of its layers.

The idea

A graph neural network (GNN) is a network that reads a graph, such as the graph of Lesson 5, and returns a short list of numbers for every node. FedBUD can give every client a copy of one shared GNN. The GNN reads the graph of the client's sub-network. A small private part of each client then turns the GNN's numbers into a scale and a shift for each layer. Each layer output o becomes o + η × (scale × o + shift).

The number η is a gate that each client learns, and it starts at zero. So in the first round the shared GNN changes nothing, and training starts from aligned averaging alone. The server averages the clients' copies of the GNN together with the aligned updates of Lesson 8. The private part and the gate stay on the client.

The paper proves that this GNN is stable. Two sub-networks with similar graphs get similar outputs from it. The shared GNN is optional, and the main results of the paper do not use it.

What the paper measured

The paper added the shared GNN to aligned co-training on all six datasets, in two series of runs with one run each. The chart shows the change in score. A bar above zero means the shared GNN helped. For the multi-task dataset, where a lower loss is better, we turn the sign so that above zero also means better.

Questions

Question 1

The gate η starts at zero. What does the shared GNN change in the first round?

Nothing. o + 0 × (scale × o + shift) is o. Each client opens the gate only as far as its own training finds it useful.

Question 2

Which parts does the server average across clients?

The third answer. The shared GNN learns from all clients, while each client keeps its own way of turning the GNN's numbers into a scale and a shift, and its own gate.

Question 3

Look at the paper's chart. Should a client switch the shared GNN on?

The changes are small and go both ways, from −0.0161 to +0.0095. With one run per setting, the comparison carries no statistical test, so the paper reports the shared GNN as optional and keeps it out of its main results. A client could try it on its own validation data and keep it only if it helps there.

Summary

    
FedBUD offers an optional shared GNN that reads each sub-network's graph and, through a private part and a gate that starts at zero, scales and shifts the output of each layer. The server averages the GNN, and the private parts and gates stay on the clients. The paper proves that the GNN is stable, but its measured effect was small and mixed, so the main results do not use it.
